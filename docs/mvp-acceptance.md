# Composer MVP 验收清单（V1 §41/§49 + V2 §88）

按规格逐项核对，全部 PASS 才算 MVP 完成。

## 验收输入
- 中文文案 60~90 秒（约 260 字）
- 视频 10~15 个（约 8s/个）
- 图片 5~10 张

## 验收项

### 文案与旁白
- [ ] 文案完整（不修改用户原文）
- [ ] TTS 完整（每场景一段音频，全拼接无断裂）
- [ ] 旁白总时长 == IR 总时长（±0.10s，主时间轴约束）

### 字幕
- [ ] 字幕完整（每场景一条，文本与原文一致）
- [ ] 字幕时间基于最终输出时间轴（与旁白同基准）
- [ ] 中文字幕可渲染（烧录后可读）

### 视觉时间轴
- [ ] 场景无 gap / 无 overlap
- [ ] 视频逐段变速（speed ∈ [0.80, 1.70]）
- [ ] 视频不足时图片补时（无闪帧：<1s 残余不硬塞图片）
- [ ] 视频 + 图片可混排
- [ ] 纯图片场景合法
- [ ] 素材不足 → MISSING_ASSET 诚实上报（不编造素材）
- [ ] >2s 图片默认轻微 motion（slow_zoom_in）

### 音频
- [ ] BGM 自动加入（库内有素材且未显式关闭时）
- [ ] BGM ducking（旁白出现时压低 -10dB）
- [ ] SFX 语义事件插入（tag 匹配）
- [ ] 无合法音频素材 → NO_BGM/NO_SFX 诚实降级（不随机抓）
- [ ] 最终音轨存在且不削波（alimiter 0.97）

### QC（确定性）
- [ ] final.mp4 存在
- [ ] 分辨率正确
- [ ] fps 正确（≥24）
- [ ] 时长 vs 旁白（±0.20s 渲染容差）
- [ ] 音/视频流存在
- [ ] 无黑帧（5 点采样灰度均值）

### 可复现（V2 §78：IR 是源代码）
- [ ] composition.json 可人读
- [ ] 改一个 speed 重渲染不重新 TTS（plans/ 产物隔离）
- [ ] QC 报告落盘 qc/deterministic.json
